# 📌 Project Overview

This project presents an interactive COVID-19 Dashboard for India created using Tableau Public. The dashboard analyzes different aspects of the COVID-19 pandemic, including confirmed cases, recovered cases, deaths, vaccination progress, testing details, age groups, gender distribution, and state-wise analysis.

The objective of this project is to transform raw COVID-19 data into meaningful visualizations that help users easily understand trends and patterns across different states of India.

# 📊 Key Features
🗺️ State-wise Death Analysis

Visualizes the total number of COVID-19 deaths across different states of India using an interactive map.

📈 COVID-19 Cases Analysis

Displays the trend of confirmed cases, recovered cases, and deaths over time, helping to understand the growth and impact of COVID-19.

👥 Age Group Analysis

Shows the distribution of COVID-19 cases among different age groups, providing insights into the most affected age categories.

🚻 Gender Analysis

Visualizes the gender distribution of COVID-19 cases, including male and female case percentages.

💉 Vaccination Analysis

Compares the number of first and second doses administered and provides vaccine-wise vaccination details.

🧪 State-wise Testing Details

Displays COVID-19 testing information for different states, including positive and negative test results.

🏥 ICMR Testing Labs

Shows the number of ICMR testing laboratories available across different Indian states.
